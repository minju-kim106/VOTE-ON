# VOTE 실행 안내

VOTE는 익명 게시글의 안전 검사를 브라우저와 서버 양쪽에서 수행합니다. 브라우저에서 HTML 파일을 직접 여는 대신 Node.js 서버를 실행해야 게시글 등록, 신고, 관리자 검토 기능을 사용할 수 있습니다.

## 실행 방법 (Windows PowerShell)

1. Node.js를 설치합니다.
2. VS Code에서 프로젝트 폴더를 열고 터미널을 실행합니다.
3. 서버를 실행합니다.

```powershell
npm start
```

서버가 시작되면 브라우저에서 `http://127.0.0.1:3000`을 엽니다. 기본 서버는 현재 컴퓨터에서만 접속할 수 있도록 설정되어 있고, 이 경우 관리자 페이지에서 신고 목록을 암호 없이 확인할 수 있습니다. 서버를 외부 네트워크에 열 경우에는 `VOTE_ADMIN_PASSWORD`에 16자 이상의 암호를 설정해야 신고 목록과 삭제 기능을 사용할 수 있습니다.

게시글과 신고 내역은 `data/board.json`에 저장됩니다. `moderation.js`의 금지 표현 목록은 `checkPost` 함수가 브라우저와 서버에서 함께 사용합니다. 표현을 바꾸거나 추가하더라도 우회 문자가 쓰일 수 있으므로 서버 검사는 항상 유지해야 합니다.

## Render 배포

Render 대시보드에서 Git 저장소를 연결해 **Web Service**를 만들고 다음과 같이 설정합니다.

- **Build Command:** `npm install`
- **Start Command:** `npm start`
- **Environment Variables:**
  - `HOST=0.0.0.0`
  - `VOTE_ADMIN_PASSWORD`: 16자 이상의 관리자 암호
  - `VOTE_PUBLIC_ORIGIN`: 배포된 서비스의 HTTPS 주소 (예: `https://서비스이름.onrender.com`)
  - `VOTE_COOKIE_SECURE=true`
  - `VOTE_DATA_DIR=/var/data`

게시글 데이터를 재배포와 재시작 후에도 보존하려면 유료 Web Service에 **Persistent Disk**를 추가하고 mount path를 `/var/data`로 지정해야 합니다. Render의 기본 파일시스템은 임시 저장소이므로 영구 디스크 없이 실행하면 게시글과 신고 내역이 재배포 또는 재시작 시 사라질 수 있습니다. 기존 로컬 실행에서는 `VOTE_DATA_DIR`을 지정하지 않으면 계속 `data/board.json`을 사용합니다.

## 안전 관련 참고

- 서버는 게시글을 파일에 저장하기 전에 욕설·비방 표현과 이름, 학번, 전화번호, 이메일, 주소, 주민등록번호 형식의 개인정보를 검사합니다. 이름과 주소 검사는 입력 문맥과 알려진 주소 형식을 이용한 패턴 검사이므로 모든 개인정보를 완벽하게 찾아내지는 못합니다.
- 브라우저 검사는 빠른 안내를 위한 것이며, 실제 등록 여부는 서버의 검사 결과로 결정됩니다.
- 이름이 문맥에 따라 쓰인 경우, 알려지지 않은 별명/비속어, 교묘한 우회 표현까지 자동으로 모두 판별할 수는 없습니다. 신고된 글은 관리자가 직접 확인해 삭제해야 합니다.
- 이 데모는 학교 학생 인증이나 인터넷 공개 서비스 수준의 보안을 제공하지 않습니다. 인터넷에 공개하지 마세요. 실제 배포에는 학교 계정 인증, HTTPS, 데이터베이스 백업 및 운영 환경에 맞는 관리자 권한 관리가 필요합니다. HTTPS 리버스 프록시 뒤에서 실행할 때는 `VOTE_PUBLIC_ORIGIN`을 사이트의 HTTPS 주소로, `VOTE_COOKIE_SECURE=true`로 설정해야 합니다.
